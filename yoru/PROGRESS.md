## Последние изменения

- Просмотр перенесён из диалога на полноценную страницу `#watch/ID/номер`: большой собственный плеер, рекомендации, компактные меню сезона/серии/озвучки. Удалена ручная загрузка файлов. Скорость/качество/PiP/кино в плеере; границы предыдущей/следующей серии скрываются.
- Автопропуск: готовые отметки источника; запасной AniSkip по MAL/номеру, только при совпадении длительности версии ±8 секунд. Никаких ручных секунд. Без подходящих отметок пропуск недоступен. Автопереход и автозапуск — независимые переключатели.
- Озвучки в одном плеере: AniLiberty и AnimeVost, когда релиз точно связан. Японская НЕ подключена; ложного пункта меню нет. Исследованные публичные дополнительные API предлагают iframe, не прямые потоки для собственного интерфейса.
- Карточка подробностей: крупная постерная колонка, полное описание, разделы и действия. Каталожные постеры 2:3, без изменения исходных файлов.
- Последняя правка пользователя: слоган «Аниме под твоё настроение» вместо отвергнутого «Следующая история — твоя». Реальные обложки меняются каждые 7 секунд, плавно исчезают/появляются; пауза при hover/focus/диалоге/скрытой вкладке. Reduced motion отключает автосмену. Есть ручные стрелки и предзагрузка.
- Пользователь отверг новую иконку с глазом. Заменена на минимальную сакуру с play в `dist/assets/yooickuu-mark.svg`. Не возвращать ни глаз, ни старого чёрного кота.
- «Выбери за меня» использует весь индекс, не только первую страницу, избегает недавних и по возможности завершённых/брошенных, даёт приоритет запланированным.
- Собственные select, обрезка аватара drag/zoom/preview/save, круглое фото, темы, профили/списки сохраняются.
- Интерфейс RU/EN/JA; внешние описания не все переведены. Нельзя обещать полную локализацию всего контента.
