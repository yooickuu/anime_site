# AniLibria: дополнительный источник

Из папки `yoru`, добавить/обновить до 20 релизов и опубликовать:

```sh
npm run add-anime -- 20 --anilibria
```

Только отсутствующие карточки (совпадающие тайтлы пропускаются):

```sh
npm run add-anime -- 20 --anilibria --new-only
```

Число — цель партии, а не обещание найти столько новых тайтлов. В обычном режиме партия включает новые карточки и дополненные существующие. Каталоги пересекаются: наличие нового источника не означает столько же новых аниме.

Без сборки/публикации: `npm run seed:anilibria -- 20`. Можно добавить `--new-only`.

- Используется официальный API: https://anilibria.top/api/docs/v1 . Токен Kodik не нужен.
- Страницы каталога и место остановки сохраняются отдельно в `src/anilibria-progress.json`. Отложенные ошибки повторяются через час; обработанные релизы повторно проверяются при изменении ревизии либо спустя сутки.
- При отсутствии данных о дате завершения обхода команда сообщает фактический результат, не выдумывает новые карточки.
- Совпадение по MAL/Shikimori/AniList/AniLibria ID; резервно — точное нормализованное название, год и формат. Конфликтующие и неоднозначные совпадения откладываются. Номера сезонов в названии сохраняются.
- Сохраняются ID карточки, существующие постеры, метаданные и дорожки Kodik. AniLibria добавляется отдельной русской дорожкой. Не выдаётся за английскую/японскую.
- Проверяются **все** опубликованные серии, дубли номеров, пропуски внутри нумерации и полнота завершённых релизов. Если серия без рабочих потоков — весь релиз откладывается.
- Для HLS проверяются манифест, завершённость, доступный сегмент и CORS. MP4 принимается только при фактическом поле API, доступном файле, CORS и длительности. Никакие URL и качества не конструируются из чужих вариантов.
- OP/ED берутся из реальных меток API; если меток нет, они остаются неизвестными.
- Новый арт проверяется загрузкой/декодированием; фон берётся только от этого релиза, без чужой общей картинки.
- Онгоинги AniLibria, включая карточки с Kodik, обновляются существующим расписанием. Ошибка одного провайдера не удаляет прежние серии.
- Отчёт: `checks/anilibria-import.json`. Запуски импорта не следует выполнять одновременно; при обнаружении параллельного изменения каталога сохранение прерывается, чтобы не затереть чужие данные.
- Новые источники уже читаются существующим плеером из media-чанка тайтла. HLS, прокси, авторизация, пользовательские списки и Supabase не меняются.
