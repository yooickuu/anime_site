# yomiku — обязательный допуск каталога, 21 октября 2026

Новый шаблон заменяет прежний (2 RU + 2 EN + JA). Непроверенное равно не допущенному. Метаданные каталога, iframe и наличие пункта в меню не доказывают наличие рабочего видео.

## Для каждого релиза и каждой уже вышедшей серии

- Две РАЗНЫЕ русские озвучки, одна английская, оригинальная японская. У студий/дорожек разные идентификаторы; копия одного дубляжа с другого сервера не считается вторым.
- По последнему решению пользователя предпочтительна настоящая 1080p; если её нет, допускается настоящая 720p для каждой выбранной дорожки. 360p и 480p продолжаем искать, но их отсутствие не блокирует допуск. В плеере только реально проверенные варианты, без переименования, апскейла и обещания перекодирования. HLS проверяется по настоящим видеовариантам, MP4 — по ссылкам API; любой заявленный вариант должен пройти проверку.
- Переключаемые субтитры RU, EN, JA, синхронизированные с каждой выбранной версией серии; текст не вшит в картинку. До реализации субтитров в плеере релиз не допускается.
- Все вышедшие серии по проверенному списку релиза, без дыр, дублей, подмены сезона или нарезок. Анонсированные, но ещё не вышедшие серии не считаются отсутствующими.
- Рабочие потоки в нашем плеере; проверены воспроизведение, перемотка, смена качества/озвучки, субтитры, CORS и отсутствие обязательного стороннего плеера.
- OP/ED: корректные метки для конкретного монтажа каждой дорожки; отсутствие OP/ED допустимо только если проверено, что их в этой серии нет. Не использовать одинаковый интервал на весь сериал. Сцены после титров сохраняются.
- Проверены автопереход и автозапуск, включение/выключение переключателей, последняя/единственная серия, сохранение полноэкранного режима. Полная проверка браузером обязательна для допуска, а не только HTTP 200.

## Изображения

- Оригинальная обложка именно этого релиза, без искусственного увеличения; ориентир минимум 800×1200.
- Отдельный качественный фон именно данного аниме, исходник минимум 1920×1080. Он передаётся прямо из проверенной записи каталога в окно, без подмены старым баннером или обложкой. Чёрно-белый на странице деталей, без растяжения или чрезмерного кропа.
- Фон занимает не менее 2/3 видимой области окна И доходит как минимум до нижней кромки обложки. Если геометрия оригинала не позволяет это без искажения — другой исходник, а не растягивание.
- Плавная прозрачная маска в реальный фон выбранной темы. Визуальная проверка desktop/mobile; автоматическое измерение размеров не доказывает красивую композицию.

## Партии, дубли и онгоинги

- По 250 кандидатов (до 1000 настраиваемым размером партии) за проход, ограниченный параллелизм и соблюдение ограничений источников. Размер партии не означает число публикаций.
- Сначала карантин/отчёт, затем атомарная публикация только полностью допущенных релизов. Никакого запасного импорта непрошедших карточек.
- MAL/AniList/Shikimori идентифицируют релиз, источники привязаны к одной карточке. Спорные совпадения на ручную проверку; не объединять разные сезоны/ремейки по похожему названию.
- Обновляющий адаптер + расписание + успешная проверка необходимы для онгоинга. Новая серия публикуется автоматически только целиком по тому же шаблону, поэтому публикация может отставать от премьеры.
- Устаревшее/ошибочное подтверждение не даёт допуск. Нельзя считать весь сериал проверенным по первой серии.

## Переход

Сначала резервная копия состояния каталога и источников; затем подготовка нового разрешённого каталога. Аккаунты, личные списки, история, плеер и дизайн не удаляются. Отдельно контролировать, чтобы старые подборки/поиск/ссылки не обходили новый допуск. До переключения всех путей на этот каталог старый сайт не объявлять очищенным.

Текущий этап: старые источники отключены в клиенте, публичные индексы/видео удалены, автоматические старые импорты выключены. Новый разрешённый каталог пуст; старый код адаптеров оставлен только для аудита вне рабочего подключения. Серверная Edge Function отдельно требует проверки после снятия публичных снимков. Новый импорт ещё НЕ подключён. Недостающие дорожки, субтитры и результаты браузерных проверок нельзя выдумывать. При нуле допущенных — честно ноль.


## Сборка нескольких источников

`src/catalog-assembly.js` объединяет записи ДО разбиения на партии по общим MAL/AniList/Shikimori ID. Разные ID одного пространства в связанной группе — конфликт и карантин, одинаковое название не является основанием для слияния. `audit:admission` уже использует этот этап.

Дорожки разных языков могут поступать от разных источников в одну карточку. Для слияния качеств/субтитров одной дорожки требуются проверенные `mappingReview` (releaseKey, episode, passed, checkedAt), совпадающие recordingId, cutId, длительность и OP/ED. Два зеркала одной студии — одна озвучка. Неполная дополнительная озвучка остаётся в heldAudio, если проверенный основной комплект уже полон.

Список вышедших серий берётся из подтверждённого releaseManifest, а не из объединения неполных источников. После сборки заново проверяется плеер: старые playerDesktop/playerMobile не переносятся автоматически на новый комплект.

`src/hls-renditions.js` исключает I-FRAME плейлисты из доступных качеств: это кадры для перемотки, а не полноценное видео. Сам плейлист не подтверждает декодирование и работу в браузере.

`python3 scripts/collect-jimaku.py` сопоставляет публичный каталог субтитров по AniList ID. Совпадение каталога не подтверждает язык, количество файлов или синхронизацию. Отчёт остаётся в checks/admission, на сайт ничего не публикует.
