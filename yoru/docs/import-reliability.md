# Импорт и автоматические обновления

Добавить до 10 новых тайтлов из каждого источника и опубликовать проверенную партию:

```sh
npm run add-anime -- 10 --both
```

`--both` последовательно обходит Kodik напрямую и AniLibria, пропуская уже известные карточки. Для новых карточек Kodik собираются дополнительные озвучки. Повторный запуск продолжает сохранённый обход. Число — цель, а не гарантия: релизы без видео, с конфликтующими ID или неполными сериями не допускаются. `--with-sources` позволяет также дополнять уже существующие карточки озвучками.

Один источник: `npm run add-anime -- 10 --updated` или `npm run add-anime -- 10 --anilibria`.

Обновление онгоингов запускается GitHub Actions каждые 6 часов (фактический запуск может задерживаться GitHub). Проверяются реальные плейлисты, сегменты и CORS. Временные сетевые ошибки повторяются до трёх попыток. Структурные ошибки, нерабочие файлы, ошибки идентичности и арты не одобряются повтором.

Очередь `src/ongoing-retries.json` сохраняет неудачные тайтлы, в том числе если другой источник уже пометил сериал завершённым. Отчёт `ongoing-update-report` в Actions содержит точные причины; частичные отказы видны как предупреждения. Существующие серии не удаляются. Перед записью проверяется целостность каталога и отсутствие параллельной записи. Git-конфликт не обходится принудительным push: локальный коммит сохраняется.

Проверка 14 ноября 2026: 119 онгоингов, 149 успешных обращений к источникам, 16 обновлённых записей, 0 ошибок. Импорт Kodik добавил «Герб демонов» с тремя озвучками. AniLibria проверена отдельно: отсутствующие в каталоге кандидаты без потоков/серий и с конфликтующими идентификаторами отклонены. 390 тестов и сборка прошли, в каталоге 8922 карточки без отклонений. Воспроизведение, HLS-прокси, авторизация и пользовательские списки не изменялись.
