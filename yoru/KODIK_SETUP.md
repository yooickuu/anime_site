# Kodik: подключение и загрузка

Официальный токен хранится только в локальном `yoru/.env`: `KODIK_API_TOKEN=ваш_ключ`. Git игнорирует этот файл. В GitHub Actions используется одноимённый Repository secret; старое имя `KODIK_TOKEN` также поддерживается.

Из папки `yoru`:

```sh
npm run add-anime -- 100
```

Команда импортирует партию, собирает сайт, делает коммит файлов каталога и push. Затем GitHub Pages публикует сайт. Число — цель новых уникальных тайтлов, а не гарантия: неподходящие записи остаются в очереди, обработка ограничена десятикратным числом кандидатов (не меньше 100) за запуск. Повторный запуск продолжает обход. Разные озвучки не увеличивают счётчик новых аниме. На ошибке импорта, сборки или Git команда останавливается без force-push.

Для проверки без публикации:

```sh
npm run seed -- 100
npm run build
```

Для плеера обновить Supabase Edge Function `anime-source` через кнопку «Скопировать подключение видео» на `https://yomiku.site/setup.html#anime-source`. Новая версия поддерживает домен yomiku.site и возвращает `kodikPlayback: true`, `version: 7`.

Без ключа команда завершится с понятной ошибкой, каталог останется целым. Резервный прежний загрузчик сохранён: `npm run seed:anilibria -- 100`.

Проверка Kodik: постер реально декодируется, фон принадлежит самому тайтлу, доступны реальные HLS-плейлисты и медиасегмент, сохраняются все переданные эпизоды всех сезонов, количество сверяется с episodes_count. Короткий SPECIAL (<180 секунд) без описания Shikimori отклоняется. Неполный перевод остаётся в очереди, готовый существующий тайтл не удаляется. Это сетевая проверка медиаданных, не просмотр всех серий человеком и не проверка доступности из каждой страны.

Разные переводы объединяются только по идентификаторам. Оригинал загружается по собственному translation ID; русская дорожка не служит запасным вариантом для японской. Внешние субтитры поддерживаются плеером; вшитые в кадр субтитры выключить технически невозможно. Скрипт не выдумывает отсутствующие VTT-дорожки.

Позиция обхода: `src/kodik-progress.json`, отчёт: `checks/kodik-last-report.json` (не публикуется). API-токен удаляется из ссылок следующей страницы до сохранения.

Онгоинги проверяются каждые 6 часов через `.github/workflows/update-ongoings.yml` в корне репозитория. Работает и ручной Run workflow. GitHub может запускать cron с задержкой. Сборка публикуется самим workflow, поскольку push с GITHUB_TOKEN не запускает второй workflow автоматически.

Команда `npm run add-anime -- 100` также ищет до трёх разных доступных озвучек Kodik для каждого импортируемого тайтла по Shikimori ID. Дорожки объединяются в одной карточке только после проверки серий. Это не гарантия трёх озвучек у каждого источника.

### Сначала популярные аниме

`npm run add-anime -- 100 --popular`

Берёт порядок популярности Shikimori, пропускает уже имеющиеся тайтлы и ищет видео/дополнительные озвучки Kodik по точному ID. Проверки потоков всех серий, артов и коротких спешлов остаются прежними. Позиция популярного обхода сохраняется отдельно от обычного обхода, следующая команда продолжает с неё. 100 — цель по новым прошедшим проверку тайтлам, а не гарантированный результат. Не запускайте второй импорт одновременно с первым.
